# Żelazny Dziennik

Apka treningowa (PWA) dla iPhone'a: trening, waga, pomiary, postępy. Działa offline, dane trzyma na telefonie i synchronizuje do arkusza Google przez Apps Script (`apps-script/Kod.gs`).

- `index.html` – cała apka
- `sw.js` – tryb offline (przy każdej zmianie podbić `VERSION`)
- `app.html` – wersja do podglądu w Claude (bez nagłówka HTML)
